# 12. Keyboard shortcuts

**Help ▸ Keyboard shortcuts** (F1) shows the exact list for your system. Some shortcuts are the operating system's
standard keys and therefore differ between Windows and Linux.

## Main window

| Command | Windows | Linux |
|---|---|---|
| File ▸ New | Ctrl+N | Ctrl+N |
| File ▸ Open… | Ctrl+O | Ctrl+O |
| File ▸ Save | Ctrl+S | Ctrl+S |
| File ▸ Save As… | none | Ctrl+Shift+S |
| File ▸ Print drawing… | Ctrl+P | Ctrl+P |
| File ▸ Quit | none (close the window, Alt+F4) | Ctrl+Q |
| Edit ▸ Undo | Ctrl+Z | Ctrl+Z |
| Edit ▸ Redo | Ctrl+Y | Ctrl+Shift+Z |
| Edit ▸ Delete item | Del | Del |
| Edit ▸ Duplicate item | Ctrl+D | Ctrl+D |
| Edit ▸ Preferences… | none | depends on the desktop |
| Help ▸ Keyboard shortcuts | F1 | F1 |

## 3D view (View menu)

| Key | Command |
|---|---|
| F | Fit all |
| P | Perspective |
| O | Orthographic |
| 1 | Shaded |
| 2 | Shaded with edges |
| 3 | Wireframe |
| 4 | Realistic materials |
| M | Measure (on / off) |
| S | Section plane (on / off) |
| Esc | Measure: clear points; second Esc leaves measure mode. Resize: cancel the drag |
| Shift (while dragging a resize handle) | 10 mm steps instead of 1 mm |

## Mouse

| Action | 3D view | Plan |
|---|---|---|
| Left drag | Orbit (or drag a resize handle) | Move the item |
| Middle drag / Shift + left drag | Pan | Middle or right drag: pan |
| Wheel | Zoom to the cursor | Zoom |
| Click | Select a part (Ctrl / Shift + click adds) | Select an item |

## Other

* **Enter** confirms a parameter, a section size and other text fields in the inspector.
* Library window: **Library ▸ Close** uses the system's close-window key (Ctrl+W, or Ctrl+F4 on Windows).
