# Посібник користувача FurnitureOS (українською)

Практичний посібник для меблярів, які працюють у настільній програмі FurnitureOS. Тут описано лише те, що програма
вміє сьогодні. Розділи з позначками **Експериментально** або **Лише командний рядок** виділено окремо.

> FurnitureOS перебуває на ранній стадії розробки (попередня збірка). Дані фурнітури, розміри побутової техніки та
> програми для ЧПК **типові й неперевірені**. Перш ніж щось пиляти чи свердлити, прочитайте [розділ 13](13-limitations-and-safety.md).

English version: [../en/README.md](../en/README.md)

## Умовні позначення

* Шлях у меню записано так: **Файл ▸ Зберегти**. Назви пунктів відповідають українському інтерфейсу програми.
  Усі довжини — у міліметрах.
* «Лише командний рядок» означає, що функція є в консольній утиліті `fos`, яка постачається разом із програмою
  (`fos.exe` у Windows), але ще не в головному вікні. Довідка: `fos --help` у терміналі.
* Кожну прийняту зміну можна скасувати через **Редагування ▸ Скасувати**. Якщо програма не приймає введене значення,
  нічого не змінюється, а причина з'являється червоним біля поля або в рядку стану.
* Повідомлення інженерних перевірок і згенеровані назви деталей («Left side») завжди англійською.
