# 12. Клавіатурні скорочення

**Довідка ▸ Клавіатурні скорочення** (F1) показує точний перелік для вашої системи. Частина скорочень — стандартні
клавіші операційної системи, тому у Windows і Linux вони різняться.

## Головне вікно

| Команда | Windows | Linux |
|---|---|---|
| Файл ▸ Новий | Ctrl+N | Ctrl+N |
| Файл ▸ Відкрити… | Ctrl+O | Ctrl+O |
| Файл ▸ Зберегти | Ctrl+S | Ctrl+S |
| Файл ▸ Зберегти як… | немає | Ctrl+Shift+S |
| Файл ▸ Друк креслення… | Ctrl+P | Ctrl+P |
| Файл ▸ Вийти | немає (закрийте вікно, Alt+F4) | Ctrl+Q |
| Редагування ▸ Скасувати | Ctrl+Z | Ctrl+Z |
| Редагування ▸ Повторити | Ctrl+Y | Ctrl+Shift+Z |
| Редагування ▸ Видалити виріб | Del | Del |
| Редагування ▸ Дублювати виріб | Ctrl+D | Ctrl+D |
| Редагування ▸ Параметри… | немає | залежить від робочого середовища |
| Довідка ▸ Клавіатурні скорочення | F1 | F1 |

## 3D-вигляд (меню «Вигляд»)

| Клавіша | Команда |
|---|---|
| F | Показати все |
| P | Перспектива |
| O | Ортогональна |
| 1 | Тонування |
| 2 | Тонування з ребрами |
| 3 | Каркас |
| 4 | Реалістичні матеріали |
| M | Виміряти (увімк. / вимк.) |
| S | Площина перерізу (увімк. / вимк.) |
| Esc | Вимірювання: очистити точки; повторний Esc — вийти з режиму. Зміна розміру: скасувати перетягування |
| Shift (під час перетягування маркера розміру) | Крок 10 мм замість 1 мм |

## Миша

| Дія | 3D-вигляд | План |
|---|---|---|
| Ліва кнопка + рух | Обертання (або перетягування маркера розміру) | Переміщення виробу |
| Середня кнопка / Shift + ліва кнопка | Панорамування | Середня чи права кнопка: панорамування |
| Коліщатко | Масштаб до курсора | Масштаб |
| Клацання | Виділити деталь (Ctrl / Shift + клацання додає) | Виділити виріб |

## Інше

* **Enter** підтверджує параметр, розмір секції та інші текстові поля в інспекторі.
* Вікно бібліотек: **Бібліотека ▸ Закрити** — системна клавіша закриття вікна (Ctrl+W або Ctrl+F4 у Windows).
