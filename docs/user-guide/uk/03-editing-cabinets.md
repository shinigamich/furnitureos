# 3. Редагування шаф

Виділіть **шафу** (а не одну з її деталей) у браузері чи 3D-вигляді. Панель **Властивості** показує назву й три
вкладки: **Параметри**, **Конструкція**, **Наповнення**. Розміри деталей завжди випливають із цих налаштувань —
вводити розмір деталі вручну не потрібно.

## Вкладка «Параметри»

1. Знайдіть параметр (параметри згруповано за типом; для пошуку за назвою є **Фільтр параметрів**).
2. Введіть число (`900`, `812.5`, `812,5`) або вираз з інших параметрів (`depth + 140`, `width / 2`).
3. Натисніть **Enter**.

* Параметри *курсивом* — **похідні** (обчислюються з інших). Введене значення їх **закріплює**; кнопка **Скинути**
  повертає стандартну формулу.
* Неприйняте значення (невідома назва, помилка у виразі, розмір, з яким шафу не побудувати) показується червоним, і
  нічого не змінюється.
* Кожна прийнята зміна — один крок скасування; меню «Редагування» називає його, наприклад «Скасувати Set width …».

## Вкладка «Конструкція»

* **Конструкція**: з'єднання кришки й дна, верх (плита чи царги), кріплення задньої стінки, цоколь (опори, цокольна
  панель із боковинами до підлоги або без цоколя), кріплення верху, дна й перегородок (конфірмати чи шканти),
  **Свердлити отвори під полицетримачі**.
* **Матеріали**: **Корпус**, **Задня стінка**, **Фасади**, **Короби ящиків**, **Дна ящиків** і крайки для **Видимих
  кромок**, **Прихованих торцевих кромок** та **Кромок фасадів** — з бібліотеки проєкту.
* **Фурнітура**: **Завіса**, **Ручка**, **Полицетримач**, **Конфірмат**, **Шкант**, **Опора**, **Розсувна система**,
  **Навіс для шафи** (необов'язково) і **Монтажна шина**. Пропонується лише фурнітура відповідного типу з бібліотеки
  проєкту. Навісу потрібна задня стінка в пазах із достатнім відступом паза (або шафа без задньої стінки); потрібний
  відступ панель підкаже.

## Вкладка «Наповнення»

Наповнення — це дерево **секцій**: угорі «Увесь простір», під ним секції кожного поділу з розміром і вмістом.
Спочатку виділіть секцію, потім користуйтеся кнопками нижче.

### Поділ на секції

1. Вкажіть **На секцій** (2–9).
2. Натисніть **Поділити вертикально** (секції поруч, між ними перегородки) або **Поділити горизонтально** (секції
   одна над одною, між ними нерухомі полиці). Нові секції отримують рівні частки.
3. Розмір секції: виділіть її, введіть значення в полі **Розмір** і натисніть **Задати розмір**:
   `300` — фіксовано 300 мм, `1*` / `2*` — частка вільного місця, інший текст — вираз (`width / 3`).

**Скасувати поділ** перетворює поділену секцію на одну порожню (фасад зберігається). **Очистити наповнення** прибирає
все: секції, полиці, фасади.

### Полиці

Виділіть секцію без поділу й задайте **Полиці** (переставні полиці, рівномірно).

### Штанга для одягу

1. Виділіть секцію без поділу.
2. Позначте **Штанга для одягу**, задайте **Висоту від верху** (вісь штанги під плитою над секцією) і виберіть
   **Штангу** та **Тримачі** з бібліотеки.
3. Натисніть **Застосувати штангу**.

Програма відмовить (і пояснить), якщо секція поділена, має переставні полиці, мілкіша за 500 мм, залишає менше
800 мм під штангою або має фасад, відмінний від одностулкових, двостулкових чи розсувних дверей. Ці межі — типові
практичні правила.

### Фасади

Виділіть секцію, у групі **Фасад секції** виберіть **Тип**, заповніть поля й натисніть **Застосувати фасад**.

| Тип | Примітки |
|---|---|
| **Без фасаду** | Відкрита секція. |
| **Одностулкові двері** | Завіси ліворуч чи праворуч; накладання; **Чашкові завіси**; положення ручки. |
| **Двостулкові двері** | Дві стулки на проріз. |
| **Блок шухляд** | **Висоти шухляд** знизу вгору через `;`, наприклад `140; 1*; 1*`. |
| **Підйомний фасад** | Навішений за верхній край; типовий підйомний механізм з кожного боку. Неможливий у секції, закритій царгами; шафу, занизьку, зависоку чи замілку для механізму, програма не прийме. |
| **Розсувні двері** | Кількість стулок 2–6 або вираз, наприклад `if(width > 2000, 3, 2)`. Вкладні стулки в типовій дворядній системі (**Розсувна система** на вкладці «Конструкція»). Секція з розсувними дверима не може мати інших фасадів. |
| **Ніша для техніки (відкрита)** | Відкрита ніша для техніки з вентиляцією за бажанням ([розділ 2](02-templates.md#шафи-для-побутової-техніки)). |
| **Декоративний фасад техніки** | Фасад, що кріпиться до дверцят техніки, без завіс. |

**Накладання**: накладний повністю, напівнакладний або вкладний (у прорізі). **Ручка**: без ручки, посередині,
вгорі, внизу.

### Короби шухляд

Для **Блоку шухляд** виберіть у полі **Короби ящиків** значення **Короб на напрямних**: за кожним фасадом з'явиться
короб (дві боковини, внутрішня передня стінка, задня стінка, дно) на двох **Напрямних** (записи бібліотеки типу
«напрямні»: кулькові або приховані) з **Дном ящика** в пазах або прибитим знизу. Розмір короба залежить від прорізу,
глибини шафи та правил напрямних. Неможливі поєднання (дно, прибите знизу, з прихованими напрямними; шафа, мілкіша за
найкоротші напрямні) програма не прийме. Матеріали коробів: **Короби ящиків** і **Дна ящиків** на вкладці «Конструкція».

### Внутрішні шухляди (за дверима)

Для гардеробів і пеналів: шухляди в секції **без поділу** за одностулковими, двостулковими або розсувними дверима
(без переставних полиць і штанги в цій секції).

1. Позначте **Шухляди за дверцятами**.
2. **Висоти**: по одному відсіку на шухляду знизу вгору, наприклад `200; 1*; 1*`.
3. Виберіть **Напрямні**, **Дно ящика**, **З'єднання ящика**, **Фасад** (лише передня стінка ящика або внутрішній
   фасад перед ящиком) і **Ручку фасаду** (виріз-ручка або без ручки).
4. Натисніть **Застосувати внутрішні шухляди**.

### Рамкові фасади з філенкою

Для одностулкових і двостулкових дверей, підйомного фасаду чи блоку шухляд виберіть у полі **Конструкція** значення
**Рамковий з філенкою** (замість **Суцільний**): дві стійки, дві поперечки й філенка в пазу. Задайте **Ширину
стійки**, **Ширину поперечки**, **Товщину філенки**, **Глибину паза**, **Зазор філенки**, **З'єднання рамки** (короткий
шип або шканти) і **Матеріал філенки** (порожньо — матеріал фасадів, із попередженням про товщину). Розміри рамки —
типові значення. Недоступно для розсувних дверей, фасадів техніки, L-подібних кутів і фігурних фасадів.

**Фасади зі склом:** ядро вміє будувати рамкові фасади зі склом у фальці (скло потрапляє в покупні вироби,
[розділ 7](07-production.md#покупні-вироби)), але настільна програма **поки не дозволяє перемкнути фасад на скло**.
Такі фасади бувають лише в проєктах чи компонентах, створених в інший спосіб.

## Окрема деталь: дані, перевизначення, контур

Виділіть деталь, щоб побачити чистовий розмір, розмір розкрою (чистовий мінус товщина крайки), матеріал, напрям
текстури, кромки й кількість операцій обробки, а також **Ідентифікатор** (потрібен для деяких консольних команд).

* **Перевизначення для цієї деталі**: інший матеріал і кожна кромка L1 / L2 / W1 / W2 — «За правилом шафи», «Без
  кромки» або крайка з бібліотеки. **Видалити перевизначення** повертає правила шафи.
* **Форма**: закруглення кутів, дуга на кромці або довільний контур, а також прямокутні чи круглі вирізи; натисніть
  **Застосувати**. Фігурні деталі фрезерують, а не пиляють ([розділ 8](08-cutting-and-nesting.md#розкладка-для-фрезера-фігурні-деталі)).
  Докладніше: [Getting started](../getting-started.md), розділ 5.
