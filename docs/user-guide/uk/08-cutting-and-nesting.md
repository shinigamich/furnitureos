# 8. Розкрій і розкладка

Відкрийте вкладку **Розкрій**. Карти розкрою створює **евристичний** оптимізатор: кожну карту перевірено незалежно
(без накладань, у межах листа), але вона **не обов'язково оптимальна**. Комерційним програмам може знадобитися
менше листів.

## Як читати підсумок

Один рядок на кожен матеріал **і спосіб**:

* **Пилка (гільйотинний розкрій)**: прямокутні деталі для форматно-розкрійного верстата — кількість деталей, листів,
  нижня межа за площею, використання та **Перевірка карти** («valid» або «problems: N»).
* **Розкладка для фрезера (евристика)**: фігурні деталі (див. нижче).

Виділіть рядок, потім **Лист** («Saw sheet 1 of 3», «Nest sheet 1 of 1»), щоб побачити карту.

## Налаштування пилки

1. **Застосувати до**: **Типові для проєкту** або окремий матеріал.
2. **Пропил (ширина пилки)**, **Обрізка зліва / справа / зверху / знизу** (торцювання краю листа).
3. **Критерій**: **Найменше листів**, **Найменше відходів**, **Спершу залишки** або **Найменше різів**.
4. Натисніть **Застосувати й переоптимізувати**.

**Використовувати для матеріалу типові налаштування проєкту** прибирає власні налаштування матеріалу. Кожна зміна
скасовується.

## Залишки (обрізки як додатковий запас)

Лише для окремого матеріалу (не для «Типові для проєкту»):

1. Виберіть матеріал у полі **Застосувати до**.
2. **Додати залишок**: позначка, довжина (уздовж текстури), ширина, кількість.
3. **Застосувати й переоптимізувати**. Залишки використовуються раніше за цілі листи.

**Видалити залишок** прибирає рядок. Залишок шириною 0 та інші неправильні значення програма не прийме.

**Склад залишків майстерні (лише командний рядок).** Спільний для всіх проєктів склад обрізків (`.fosremnants`)
ведуть командою `fos remnants`: `list`, `add`, `remove`, `import-offcuts` (зберігає обрізки з карт проєкту, типово не
менші за 300 × 100 мм) і `use` (розкроює проєкт, спершу використовуючи плити зі складу; без `--commit` — лише пробний
прогін). Довідка: `fos remnants --help`.

## Розкладка для фрезера (фігурні деталі)

Деталі з непрямокутним контуром (закруглені кути, дуги, вирізи, через які контур не прямокутний) не пиляють. Вони
подані як **фрезеровані деталі** з розміром заготовки й розкладаються окремо на власних листах.

**Налаштування розкладки для фрезера (усі матеріали)**: **Діаметр фрези** (деталі розносяться на нього), **Зазор**,
**Допуск хорди**, **Поле ліворуч / праворуч / зверху / знизу**, **Ітерації**, **Початкове значення (seed)** (те саме
значення — та сама розкладка). Натисніть **Застосувати й перерозкласти**.

Фігурні й пиляні деталі одного матеріалу ніколи не потрапляють на один лист. Якість розкладки не перевірялася на
еталонних задачах.

## Експорт

Плани розкрою входять до виробничого пакета ([розділ 7](07-production.md#виробничий-пакет-усе-в-одному-документі)) і
до вікна виробничої партії (**Експорт карт розкрою (SVG)…**). Із командного рядка: `fos cut`.
