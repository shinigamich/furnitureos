# 4. Матеріали, крайки, фурнітура та редактор бібліотек

Кожен проєкт має власні **бібліотеки**: матеріали (плити, скло), крайки та фурнітуру. Шафи посилаються на записи
бібліотеки за ідентифікатором. Новий проєкт починається з **типових записів-заглушок**: без виробника, ціна 0
(= невідома), приблизні розміри. Перш ніж рахувати кошторис чи запускати виробництво, замініть їх своїми.

## Як відкрити редактор

**Проєкт ▸ Бібліотеки…** відкриває вікно **Бібліотеки проєкту** з трьома вкладками: **Матеріали**, **Крайки**,
**Фурнітура**. У списку — усі записи; підказка «Used by» називає вироби, що їх використовують.

Кнопки: **Новий**, **Дублювати** (створює `<id>-copy`), **Видалити**, **Застосувати**. Кожна застосована зміна — один
крок скасування в головному вікні. Неправильні значення програма не прийме й пояснить причину.

## Матеріали

1. Вкладка **Матеріали** ▸ **Новий** (або **Дублювати** наявну плиту).
2. Заповніть: **Ідентифікатор**, **Назва**, **Виробник**, **Код**, **Постачальник**, **Тип**, **Товщина**, **Довжина
   листа**, **Ширина листа**, **Текстура** (видима текстура вздовж довжини листа), **Колір**, **Доступний**.
3. Ціни: **Ціна за лист** і/або **Ціна за м²** (0 = невідома). Кошторис бере ціну за м², коли плити рахуються за
   площею, і ціну за лист, коли використовуються карти розкрою ([розділ 9](09-quotes.md)).
4. **Щільність** (кг/м³, 0 = невідома): потрібна для ваги пакунків у пакувальному листі. Вага ніколи не вгадується.
5. **Застосувати**.

Як призначити матеріал: виділіть шафу ▸ вкладка **Конструкція** ▸ **Матеріали**, або деталь ▸ **Перевизначення для
цієї деталі**.

## Крайки

Поля: **Ідентифікатор**, **Назва**, **Виробник**, **Код**, **Тип**, **Товщина** (додається до кромки панелі; розмір
розкрою зменшується на неї), **Ширина стрічки** (має перекривати товщину плити), **Колір**, **Ціна за метр**.

## Фурнітура

Можна змінювати: **Ідентифікатор**, **Назва**, **Виробник**, **Код**, **Ціна за штуку**.

* **Тип і схема свердління беруться з вбудованого каталогу й тут не редагуються.** Щоб додати фурнітуру,
  **Дублюйте** запис того самого типу та перейменуйте його.
* **Розміри** показує, чи запис «Перевірено за технічними даними виробника», чи «Не перевірено (типові або
  неперевірені розміри)». Уся вбудована фурнітура — **не перевірена**.

> **Безпека:** типові завіси, напрямні, підйомні механізми, розсувні системи, навіси, шини й ніжки мають координати
> отворів, *не* взяті в жодного виробника. Перед свердлінням звірте кожну позицію з технічними даними справжньої
> фурнітури ([розділ 13](13-limitations-and-safety.md)).

## Перенесення бібліотек між проєктами

* **Бібліотека ▸ Експортувати файл бібліотеки…** зберігає всі записи у файл `.foslib`.
* **Бібліотека ▸ Імпортувати файл бібліотеки…** читає `.foslib`. Якщо запис із тим самим ідентифікатором, але іншими
  даними вже є, виберіть **Залишити наявні**, **Замінити наявні** (зміниться кожен виріб, що його використовує) або
  **Додати як копії** (нові ідентифікатори `<id>-imported`). Імпорт — один крок скасування.

Порада: заведіть один «майстерняний» проєкт зі своїми плитами, крайками та цінами, один раз експортуйте його й
імпортуйте цей файл у кожен новий проєкт.

## Примітки

Видалити запис, який використовується, не можна. Назви в бібліотеках — це дані, вони не перекладаються.
