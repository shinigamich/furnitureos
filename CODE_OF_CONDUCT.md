# Code of Conduct

## Our pledge

We want FurnitureOS to be a welcoming project for furniture makers, engineers and developers of every
background and experience level. Participants are expected to help keep it that way.

## Expected behaviour

* Be respectful and constructive; assume good intent.
* Criticise ideas and code, not people.
* Welcome newcomers and explain reasoning; domain knowledge from the workshop floor is as valuable as code.
* Be honest about what works and what does not.

## Unacceptable behaviour

* Harassment, discrimination, personal attacks, or sexualised language or imagery.
* Publishing other people's private information without permission.
* Sustained disruption of discussions.

## Enforcement

Project maintainers may edit or remove contributions that violate this code and may temporarily or
permanently exclude participants. Report problems privately to the maintainers through the contact
options on the repository owner's GitHub profile or via a private security advisory. Reports are handled
confidentially.

## Scope

This code applies in all project spaces (issues, pull requests, discussions) and when representing the
project in public.
